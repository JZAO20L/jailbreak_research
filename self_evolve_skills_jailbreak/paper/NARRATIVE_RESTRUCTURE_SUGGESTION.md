## 🎯 为什么以PAIR+SESS为主干？

### 1. 数据消融更有说服力

```
PAIR baseline: 55.5% → 提升空间大
PAIR+SESS: 79.0% → +23.5pp (42.3%相对提升)

vs.

AutoDAN baseline: 86.8% → 已经很高
DAN+SESS: 100.0% → +13.2pp (15.2%相对提升)
```

**结论**：从低基线提升到高水平，效果更显著 ✅

---

### 2. 迭代优化更清晰

```
PAIR: ~20次迭代 → PAIR+SESS: 4.45次
- 减少77.7%
- 基线清晰（业界标准的20次）

vs.

AutoDAN: ~50次迭代 → DAN+SESS: 1.10次
- 减少94.5%
- 但AutoDAN本身是进化方法，对比不够纯粹
```

**结论**：PAIR对比更纯粹，体现SESS的"shortcut"效果 ✅

---

### 3. 叙事逻辑更连贯

```
当前叙事（混合）：
- PAIR+SESS: +23.5pp
- DAN+SESS: +13.2pp
- 两者并列，主线不清晰

建议叙事（PAIR为主）：
- 主线：PAIR+SESS显著提升（+23.5pp, ↓77.7%迭代）
- 扩展：强先验（DAN）整合可达100% ASR
- 逻辑：先验证框架有效性，再展示强先验能力
```

**结论**：主次分明，叙事更清晰 ✅

---

### 4. 实验解释更自然

```
PAIR系列：
- 空库启动 → 验证SESS框架本身有效性
- 数据消融 → 清晰展示数据策略影响
- Evolution动态 → 高水位下的边际优化

DAN系列：
- 强先验效果 → 展示框架整合能力
- 数据效率 → 证明强先验价值
- 但不适合作为主要消融对象（已有强先验）
```

**结论**：PAIR系列更适合系统消融 ✅
