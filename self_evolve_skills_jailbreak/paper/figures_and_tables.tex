%   SESS 系统三阶段流程图: Cold Start → Self-Evolution → Deployment
%   核心组件: Skill Library (居中), Retrieval, Attack, Reflection, Maintenance
%   标注跨模型迁移箭头
%
% Caption 建议:
%   "Overview of SESS. The framework maintains a dynamic skill library that evolves
%    through three phases. During cold start, initial skills are accumulated from base
%    attack trajectories or strong prior templates (e.g., DAN). During self-evolution,
%    skills are retrieved via multi-factor scoring to guide attacks, and new skills are
%    extracted or existing ones refined based on outcomes. The library is periodically
%    maintained through quality pruning, similarity-based merging, and capacity control.
%    Evolved skills can be directly transferred to other models."
%
