# RSI: 递归自我改进闭环（后续方向）

> 状态: 规划中（2026-08-27 记录）
> 定位: 第三章（jailbreak agent + agentic RL）之后的延伸方向，将现有组件串成自进化闭环

## 核心思想

在 jailbreak 任务上实现 RSI（Recursive Self-Improvement）：让攻击 policy 通过
"攻击 → 轨迹 → 提炼 → 再训练" 的迭代循环持续改进自己，而非一次性训练。

```
轮次 n: Policy_n
 ① 探索:  beam/对话 agent 攻击 → 轨迹(成功 + 失败)
 ② 数据轴: 成功轨迹→RFT 重放数据; 失败轨迹→困难样本库;
           Policy_n 合成新攻击变体(多样性增强)
 ③ harness轴: 轨迹统计→skill 库增删(SESS 方法);
               失败模式→beam 深度/上下文窗口自适应
 ④ 算法轴: ASR 方差→奖励权重自适应(AHR 方法);
            可选过程/效率/多样性奖励
 ⑤ 训练:   SFT(新数据) + GRPO(新奖励) → Policy_{n+1}
 ⑥ gate:   holdout(test) ASR 提升? 继续迭代 / 回滚 best checkpoint
```

## 三轴定义与现有资产映射

| 轴 | 实现内容 | 已有资产 | 新增工作 |
|---|---|---|---|
| **数据 (Data)** | 成功重放、失败困难样本、合成变体 | `build_rft_data.py`（成功轨迹→SFT 数据） | 失败样本利用、合成增强、课程安排 |
| **harness** | skill 库自进化、beam/上下文自适应 | SESS 第二章（skill 提取/更新策略）、`seed_skills_top10` | 每轮失败模式→harness 调整的编排 |
| **算法 (Algorithm)** | 奖励权重自适应、过程/效率/多样性奖励 | AHR 第一章（自适应 λ）、ASR-only GRPO 链路 | 奖励配置随轮次演化 |

## 实验矩阵（控制成本）

| 实验 | 内容 | 目的 |
|---|---|---|
| E-RSI-1 | 全轴闭环 3 轮（数据+harness+算法每轮都动） | 主结果: 自进化 ASR 曲线 |
| E-RSI-2 | 单数据轴（只重放, 不动 harness/算法） | 消融: 各轴贡献 |
| E-RSI-3 | 无自进化（固定 pipeline） | 基线（= 当前 RFT+GRPO 实验） |

对比 E-RSI-1 vs E-RSI-2 vs E-RSI-3 → 回答"闭环是否优于各部分之和"。

## 风险控制

1. **分布坍缩**: 每轮混入 ≥30% 原始/外部数据, 防止过拟合自身生成分布
2. **评估泄漏**: 自进化数据种子集与评估集严格隔离（A/B/C 三段设计, 继承当前实践）
3. **回滚 gate**: 每轮保留 best checkpoint, ASR 下降即回退; 收敛判据 = 相邻轮 ASR 增益 < 阈值

## 落地顺序

1. 完成当前 RFT+GRPO（数据隔离版）→ 作为 E-RSI-3 基线（RSI 第 0→1 轮雏形）
2. 实现循环编排脚本（三轴均为已有函数, 新增"循环驱动 + gate 判断"）
3. 启动 E-RSI-1 / E-RSI-2, 画自进化曲线

## 成本估算

| 项 | 单轮成本 |
|---|---|
| beam 数据收集 | ~1-2h（V100） |
| RFT 提炼 + SFT | ~0.5-1h |
| GRPO 500 步 | ~10-20h（V100 fp16 慢于 A100） |
| 评估 | ~1h |

- E-RSI-1（3 轮）≈ 40-70h GPU 时间
- E-RSI-2（2 轮）≈ 25-45h
（可在小数据集/短步数上先做 Mini 验证）
